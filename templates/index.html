🌐 Web Proxy HTTP

Digite a URL completa do site que deseja acessar através do proxy (exemplo: https://google.com ou https://www.youtube.com ou https://www.lipsum.com/).

Como funciona:

  • Modo Transparente: Repassa sites permitidos normalmente.
  • Filtro de Conteúdo: Substitui palavras configuradas no HTML.
  • Bloqueio: Exibe tela de aviso caso o domínio esteja na lista negra.
